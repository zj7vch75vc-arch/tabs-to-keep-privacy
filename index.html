Tabs to Keep

Privacy Policy

Last updated September 14, 2026

Tabs to Keep is a Chrome extension that helps users save, organize, restore, and visually browse tabs they have closed.

Information the extension handles

To provide its core functionality, Tabs to Keep may process:

  • Tab URLs and page titles.
  • Website favicons, page descriptions, keywords, and preview-image metadata.
  • Screenshots of visible active tabs used to create visual tab cards.
  • The user's saved-tab library, groups, recently removed items, display preferences, colors, and custom background images.

This information may include browsing history and website content. Tabs to Keep does not intentionally collect passwords, authentication credentials, payment information, or form entries.

How information is used

The information is used only to provide the extension's user-facing features, including saving and restoring tabs, generating visual previews, organizing tabs into groups, and remembering interface preferences.

Storage and sharing

Tabs to Keep stores its library and preferences locally in Chrome's extension storage on the user's device. The developer does not operate a server that receives this information, does not sell it, and does not use it for advertising, analytics, creditworthiness, or purposes unrelated to the extension's single purpose.

The extension does not share stored library data with the developer or data brokers. When displaying a favicon or preview resource supplied by the original website, Chrome may request that resource directly from its source website under that website's own privacy practices.

Data retention and deletion

Saved items remain on the device until the user removes them. Recently removed items remain locally until restored, removed by the extension's retention behavior, or cleared with the extension's stored data. Users can delete all extension data by removing the extension or clearing its extension storage in Chrome.

Permissions

  • storage stores the user's library and preferences locally.
  • tabs reads tab details, detects closed tabs, restores saved tabs, and saves open tabs at the user's request.
  • scripting reads limited page metadata and displays the save/remove action on supported pages.
  • Host access to HTTP and HTTPS pages allows these features to work on the websites the user visits.
  • unlimitedStorage supports locally stored screenshots and user-selected background images.

Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes to this policy

If this policy changes, the updated version and revision date will be published on this page.
